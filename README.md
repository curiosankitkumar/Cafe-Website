# Cafe Website

A simple and responsive cafe website developed using HTML, CSS, and JavaScript.

## Features

- Attractive cafe homepage
- Food and beverage sections
- Responsive design
- Interactive JavaScript functionality
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was developed to practice frontend web development concepts including webpage structure, styling, responsive design, and JavaScript-based interactivity.


## Project Preview

This website provides a simple online interface for a cafe where users can view cafe information and available items.
